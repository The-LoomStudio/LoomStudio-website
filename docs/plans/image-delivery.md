# 图片交付与按需加载

状态：实现及本地客观浏览器验证完成；待人工画质验收与部署后的缓存验证。

## 范围

- 保留现有 PNG 原件、构图、图片比例、视差和设备切换行为。
- 使用 Astro 内置图片服务，在构建期生成 WebP、多尺寸与内容哈希地址。
- 首屏只主动加载当前画面；底部 Banner 接近章节末尾才加载，轮播切换等待目标图片就绪。
- 点击放大才请求大图；设备演示接近视口再激活，可选草稿展开后才加载代码。
- Cloudflare Pages 仅为 `/_astro/` 指纹资源设置一年缓存，HTML 与固定地址资源保留默认校验。
- 不增加全屏加载页、Service Worker、R2 或图片服务依赖；不删除原图、不改写历史、不自动提交或部署。
- 用户补充：待加载及失败图片不显示浏览器破图图标或替代文字，保留尺寸与无障碍描述；轮播失败保留当前画面。
- 用户补充：竖排视差的全部图片接入 ZoomImage，与其他图片共用按点击加载大图及关闭交互。
- 用户补充：ZoomImage 的遮罩颜色与背景模糊随展开/收起渐变，遵守减少动态效果设置。

## 实施与验证

1. 图片处理、响应式引用与缓存头。
2. 按需加载和失败时保留当前图片。
3. 构建验证派生资源、缓存头、引用与体积；浏览器客观检查冷加载、轮播、放大、草稿展开及重复访问。

构建期压缩是有损展示优化，不称为无损；透明通道需要保留。主观画质与动画验收由用户完成。
本地预览不模拟 Pages 的响应头处理，线上 CDN 命中与缓存头必须在后续部署后验证。

## 实际交付与验证记录

- Astro 在构建期生成 135 张不同尺寸/质量的 WebP，合计 17,437,678 bytes。这是全部派生版本的产物大小，不是单次访问的下载量。
- 原始 PNG 未删除、未改写，仍会随 public 目录发布；本次优化的是浏览器使用的资源与加载时机，不宣称发布目录或 Git 历史体积已缩小。
- 首图使用两个分层资源，不再额外请求不可见合成图；底部图片由文档流中的章节边界触发加载，非当前轮播图片按切换请求。
- 对现有 Sharp 0.35.4 增加直接开发依赖。其原先只是 Astro 的可选传递依赖，构建产物中动态导入失败；显式声明后目标 Node 22.18.0 构建通过。没有引入新图片平台。
- 删除首页已禁用、立即移除但仍含 eager 图片的 IntroLoader。
- Node 22.18.0 构建通过，13 页；保留可选草稿的大 JS chunk 警告，不通过调高阈值隐藏。
- 桌面 1440×900@1 和移动端 390×844@2 的独立 Chrome 上下文验证：初始图片请求分别 17/14 个，图片响应体分别 1,797,285 / 1,911,117 bytes。包含浏览器原生 lazy 预取的邻近资源，不是整个页面总流量，也不是线上测速。
- 初始请求不含后续 Banner、底部 Banner、合成放大图、DeviceShowcase 或 StudioDemo；设备进入附近后激活，草稿展开后才加载。设备双 Tab 切换通过。
- 轮播目标延迟 1.8 秒时保留当前画面；目标失败不替换当前画面。竖排末图点击后请求 2560×1707 大图，桌面/移动端显示比例正确，Escape 关闭通过；无页面异常。
- 注入竖排末图 404 后图片 opacity 为 0，保留 466.5px 高度和 alt 描述，没有打开空白弹窗。
- 动画正常模式下实测遮罩 blur 在打开/关闭途中分别为约 6.70px / 5.63px，完成后为 10px / 关闭；减少动态效果模式走直接关闭。
- 本地测试 HTTP 服务按提交的 `_headers` 规则响应，重复导航的 WebP 网络请求为 0。这只证明浏览器策略可用，不证明线上 Cloudflare 响应头或边缘命中。
- `git diff --check` 通过。客观浏览器探针为本次临时脚本 `/tmp/loom-image-delivery-check.mjs`，未引入测试框架。

## 待验收与现有限制

- 由用户验收 WebP 画质、透明人物边缘、视差及放大动画的主观效果。当前仅生成 WebP，未额外生成 AVIF，避免重复格式增加构建与维护成本。
- 部署后检查实际 HTML/图片响应头、冷缓存与复访瀑布；本轮未提交、push 或部署。
- 现有 Footer 在页面绝对底端会覆盖底部 Banner 切换按钮。浏览器记录了点击命中问题；在 Footer 尚未盖住按钮的位置验证轮播通过。本轮未扩大范围修复其布局。
- 无 JavaScript 时，当前依赖加载状态显隐的图片不会显示；网站互动演示本身依赖 JavaScript，本轮未新增独立无脚本图片呈现路径。
