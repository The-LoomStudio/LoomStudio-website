# 产品演示设备外壳

状态：实现与自动化验证完成，待浏览器交互与视觉验收。

目标：使用 Devices.css 的 MacBook Pro 与 iPhone 14 Pro 外壳承载真实 StoryDemo。
默认手机，顶部 Tab 可切换电脑，每次仅显示一台设备；设备仅是网页演示，不代表原生客户端发布状态。

范围：ProductPreview、DeviceShowcase、设备展示样式、package.json 与锁文件。
保留故事交互、组件草稿入口及现有页面滚动，不重写设备外壳，不新增设备截图或业务 API。

实施：
1. 安装 devices.css 0.2.0，使用库的标准结构；隔离通配 display 重置对内部应用的影响。
2. 外壳等比缩放，屏幕内独立滚动；手机留出摄像头与底部手势区。
3. 仅挂载一个 StoryDemo，切换设备只改外壳类名，不重置输入和故事进度；Tab 支持键盘导航。
4. 内部 UI 使用独立逻辑视口：电脑 1280px、手机 390px；根据屏幕内容区整体等比缩放，扣除摄像头/手势区的安全间距，不逐项修改字号来模拟缩放。

验证：定向尺寸与 ID 配置核对；Astro check；因新增依赖运行生产构建。
浏览器真实点击、滚动与主观视觉验收单独记录，不以构建通过替代。
