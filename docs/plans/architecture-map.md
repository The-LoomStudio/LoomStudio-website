# 开发者架构地图

## 目标与边界

在 `/docs/architecture` 提供人类可读的只读架构地图，支持缩放、平移、路径高亮、节点详情和搜索定位。只修改 website；不连接 Studio Server，不写工作区数据，不部署。

事实来自 2026-10-01 LoomStudio 本地工作区及正式架构文档。工作区含未提交改动；公开源码链接仅指向基线提交 `efc45a4fe140686459e46f48da3de7c32672c5b0`，不是已发布的精确行为快照。

## 最小实现

1. 使用 React Flow 和固定布局，区分全局模块与操作流程两个视图。全局以六个系统边框容纳 25 个模块，展示七条基础调用主干；完整的模块级关联保留在节点详情中。
2. 编排导入角色、创建 Timeline、发送正文、模型工具循环、安装扩展五条路径；流程逐步展开节点和连线，重复访问同一模块时展示独立步骤，避免全图连线交叉。
3. 独立宽屏文档路由；从文档概览与侧栏提供入口，但不加入文章连续加载队列。
4. 沿用 website 主题与圆润字体，以相片、账页、票据、对话、授权章、拼贴、模型入口和便签区分节点；在部分节点和系统边框加入白色描边文字、图标贴纸。使用现有 Nom 图片及明确标注的假设示例，不表示已存在可导入的 Nom 角色包。
5. 角色包节点使用 `cards/display/card-001.png` 的竖版封面，保持完整比例；Nom 表情图仅用于说明和示例贴纸。
6. 画布全屏铺底，Header / Footer 为透明容器、控件为半透明浮层，侧栏独立贴近窗口右侧并拥有全高滚动区。复用 website Menu 按钮、主题切换和导航页，菜单中独立列出架构地图；发布页架构章节提供入口。
7. 侧栏开关固定在窗口右上角；初始收起，展开、收起不换位置。术语支持 Hover 与点击，Settings / Preset / Timeline / Session / Run / inputNodeId 提供源码核对的结构节选和字段解释。
8. “发送正文”首节点包含本地模拟输入；沿七条连接逐段播放荧光路径，区分等待、处理、已到达状态，支持停止与再次发送。固定节拍不表示真实耗时；不发送网络请求、不写业务数据，切换路径或卸载时清理计时器。

## 验收

- 主验证：website 静态构建，覆盖 Astro 路由、React 集成与新增依赖打包。
- 定向验证：地图数据引用完整性、路径连通性和源码位置存在。
- 客观浏览器检查：路径切换、搜索定位、节点详情、缩放控制和窄屏尺寸。
- 人工验收：整体布局、阅读体验和交互手感由用户确认。

## 状态

实现完成，等待人工视觉验收。只修改 website，未部署。

- 数据完整性核对通过：25 个模块、六个分区、36 条关系、五条连续操作路径；引用的本地源码文件和行号存在。
- 定向 TypeScript 检查通过；Astro 静态构建通过，共 14 个页面，包含架构地图和优化后的 Nom 图片。
- 客观浏览器诊断通过：两种视图、25 个全局节点、侧栏收起、图片加载；五条流程分别显示 6 / 6 / 7 / 9 / 3 条连线，标签没有覆盖节点，路径采样没有命中节点内部。
- 最新全局诊断通过：六个系统边框均有实际边线；七条系统主干路径的采样没有命中系统内部，标签没有覆盖系统边框。文字贴纸的计算样式为 3 / 4px 白色描边；角色卡封面加载为竖图并使用 contain 保留比例。
- 390px 窄屏的两种视图没有横向页面溢出。节点标题没有检测到横向溢出，流程节点的正文与尾部元素没有检测到重叠。
- 本轮浮层诊断通过：1280 × 720 与 390 × 844 下画布均铺满窗口；Header / Footer 容器透明，侧栏上下仅留 12px，不受 Header 限高；右上角开关在展开和收起时坐标不变。
- 六个菜单位置逐一检查通过：远端选项隐藏且不接收点击，当前标题不再与未定位的选项重叠；菜单打开后，动态挂载的地图主体也会进入 inert 状态。
- 术语交互诊断通过：Settings 点击能打开字段说明和 JSON 结构节选，没有嵌套按钮。发送正文模拟完成七段连线；停止、再次发送、切换路径后的动画及计时器清理均已检查。
- 已调整：不再使用最初的大色块和全图全部连线；全局使用低填充边框和系统之间的七条主干，流程使用宽间隔折返路径。侧栏可收起，搜索和缩放控制保留。缩小后不再隐藏节点职责，避免总览只剩标题。
- 本轮调整：保留 Menu 的二维循环切换，不改为 3D 布局；修复新增第六项后偏移为 ±3 的选项回落到中心的问题。复用已有导航，从 Menu 与发布页架构章节进入全屏地图。
- 环境限制：执行环境为 Node 26.8.2，不是项目声明的 Node 22；构建仍通过，但未在声明版本复验。构建提示部分 chunk 超过 500 kB。
- 未验证：人工视觉与交互手感、线上部署、真实 Studio Server / Provider 行为。部署、自动源码扫描、可编辑架构、自动布局和未完成 Run 的重启恢复不属于本次范围。
