## 2026-10-13：按图的语义组织视图

- 工作流：按职责分层，表达工具循环、完整回复、截断续写与中断记录。
- 数据流：来源 → 筛选组合 → 加工 → 请求与恢复投影，分开 Content 贡献和 Native 工具规范。
- 生命周期：仅采用 Server AgentRun 状态。恢复请求创建新身份；放弃是标记与 Transcript 记录，不能伪造为 Server 状态。
- 调用时序：明确正文先提交，再校验已有主写作 Session 并创建 Run。修正旧导览中“自动选择或创建 Session”的错误描述。
- 29 个语义节点与 31 条关系各带固定提交源码依据；点选关系可查条件、限制和来源。布局与内容由本仓库维护，语义数据集中在 semantic-scenes.ts。
