# 故事工作文件演出

首页 `/#story-workspace`，紧接 PromptComposition。按用户要求直接在正式首页迭代的中文设计草稿；不是主应用业务集成，其他语言首页也暂时展示此中文演出（区块标注 lang）。替换原 manifesto / system 两段重复说明，诺姆导览与首页锚点同步更新。

32 秒单次演出：慢速打开并写入伏笔 → 策划读取、创建大纲 → 叙事 / 策划 / 记录三个示例 Agent 加速创建、读取、更新、删除工作文件 → 独立 Session 交接便笺 → 读回伏笔，正文回收线索。右侧无边框目录与正文直接铺在页面上，文件列表逐渐增加；左侧诺姆四种表情交叉过渡。使用现有图片管线与设计变量，没有新依赖。按后续反馈移除外框、内部格线、叠层重影、阴影及目录底色，以间距和选中文字颜色区分区域。

事件表是本地确定性脚本，示例分工不是产品默认自主协调承诺。工具权限、预设等真实配置未接入。Session 交接独立展示，不伪装成 Workspace 文件；官方剧情记忆扩展在说明中单独介绍。

进入视口后播放一次，离屏 / 后台暂停；显式暂停、重播、阶段定位；点文件暂停后查看当时内容，继续恢复跟随。减少动态效果展示最终文件及正文，禁用播放与阶段动画，仍可查阅文件。SSR 输出完整终态。移动端文件列表横向滚动、编辑器下置。

只使用一个 RAF 时钟，每秒最多更新文字 20 次；历史操作最多显示三条，不创建字符节点或无限增长日志。没有存储写入、模型调用、业务请求。

待用户验收：首段可读性、加速段密度、诺姆表情、结尾停驻和窄屏实际观感。

协作视觉修订：移除顶部 Agent 状态栏，以蓝 / 紫 / 金的文字锚定指针表现叙事、策划、记录的落笔位置。更新保留相同前后文，先选中旧范围，再删除并流式插入；原作者指针短暂停留，展示交接修订。目录用绿色 + / ± 与红色删除线 − 表示变更，删除项保留 1.5 秒后移除。指针随行内文字自然换行，无逐帧位置测量。仍为协作演出，不表示产品提供多人在线文档编辑。

目录视觉后续修订：取消目录红绿 diff 配色与 + / ± / − 标记，恢复中性文件名，仅突出当前选择。目录和正文之间保留一条细分割线，窄屏上下布局改为横线。正文选区、删改与彩色 Agent 指针保留。

排版精简：移除英文眉题、贴纸署名、对白阶段标题、状态修饰、操作日志、底部声明和横贯页面的进度线；阶段按钮改为带无障碍标签的小圆点。工作交接与剧情记忆改为目录下方的可选参考条目，与普通工作文件留间距，不作为实际 Workspace 文件写入。交接阶段自动打开交接内容。主标题去掉标点。剧情总结说明只在选中剧情记忆时展示。
