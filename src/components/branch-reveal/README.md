# 分支画廊滚动揭示

首页 StoryParallaxWall 全部 15 张图片使用分支文字、ASCII 扩散、图片显影。保留错落位置、快慢视差和 ZoomImage 放大，不添加树形分割线。

最新交互改为随滚动正向 / 逆向播放，不保留历史最大进度。前、中、后段分别使用 86%、78%、68% 视口高度作为滚动区间。文字展开后留出阅读区间，收去文字后才扩散，再显影插画。图片采样或缩略图未就绪时停留在文字阶段，素材加载结束后回到当前滚动进度。固定文本是视觉示意，不是真实模型推理。

仅有专属文案的主图下方保留分支标符和选择文案，用幅度受限的小视差跟随对应图片。占位图片不显示底部文字浮层；加载阶段仍使用通用推演段落。雨伞图移到中段前景层，并增加与城堡、温室图的纵向间隔。

减少动态效果、键盘聚焦图片时显示完整图片。无 JS 保留图片和说明。监听与 RAF 卸载时清理；采样错误结束动效，原图片组件继续负责图片加载反馈。

Astro 类型检查与首页输出可验证集成；实际滚动节奏、文字密度和遮挡由用户验收。
