# 对白 → 文字 Logo → SVG 转场实验

开发入口：`/dev/preview/text-logo`，只在开发模式注册。正式首次加载使用文字方案；Menu 打开使用描边方案，关闭使用拉帘。

`TextLogoTransition` 接收 `progress`、`reducedMotion` 与后景 `children`，复用现有 `LogoTransition` 的 SVG 镂空揭幕。阶段为：

- 0–20%：中、日、英固定演示对白按阅读顺序逐字流入，光标跟随输出位置；全文出现后再汇聚。
- 20–50%：原字符沿路径汇聚，保留原始中文、日文、英文字母与标点，不替换为符号。
- 50–55%：保持字符标志。
- 55–65%：与同位置、同灰阶的 SVG 交叉淡化。
- 70–100%：透出后景，放大穿过圆心。

`ascii-points.json` 为已有 `public/brand/loom-mark.svg` 在 1254 × 1254 坐标内采样的 579 个字符中心点及灰色填色。采样网格起点 (196,192)，步长 (22,28)，保留 alpha > 200 的点。不是独立手描轮廓，修改原 SVG 后需要重新采样。对白为固定演示文本，不调用模型或业务服务。

预览提供 A/B 方案切换、播放暂停、拖动进度及阶段定位。文字版实验时长 8 秒，描边版 5.8 秒；这些是便于观察的演示节奏，正式加载中，文字流入约 1.8 秒，汇聚形成 SVG 约 0.9 秒，完整标志停留约 0.3 秒，资源就绪后揭幕约 1.2 秒。系统减少动态效果时跳过字符运动，使用 SVG 淡出。

已验证：Astro check 0 errors / 0 warnings（24 hints），预览入口 HTTP 200；1200 × 750、390 × 487.5、320 × 400 的文字布局坐标均在画面内。未进行浏览器主观视觉验收，字符可读性、汇聚节奏和移动端实际表现待人工确认。
