# Prompt 构建演出

首页 `/#prompt-builder`，位于角色工作台之后、故事工作文件演出之前。直接在首页迭代，无独立预览入口。

22 秒纵向组装演出，由同一个 progress 控制展开高度和逐字内容，无横向位移：

1. system 预设节点、叙事身份逐行展开。
2. `@lore.stable` 出现，再补入「诺姆的世界」来源组，包含人物设定与世界观。
3. 本次输入命中「书」，`@lore.lower` 内补入同一 Lore 的阅读场景组。「雨」未命中，雨夜条目仅留在来源目录。
4. `@chat.session` 作为 Message 同级序列，依次补入 user 历史与 assistant Narrative 正文。
5. 独立 user Message 的 `@chat.input` 补入最新输入。
6. 左侧于 70% 前完成，右侧从 72% 开始 ASCII 显影，再出现角色插画与回应。移除原右侧同时运行的推演文本。

左侧 Lore 文件夹用蓝色图标标识常驻、绿色图标标识关键词，并显示条件文字；同一 Lore 在每个目标 Anchor 内按来源聚合。演出样例显式将常驻条目指向 stable、关键词条目指向 lower，不能理解成所有激活类型均被系统强制映射到这些锚点。来源不移动、不修改，不将所有条目自动激活。

语义依据为主应用 `packages/application-runtime/src/prompt/default-preset.json` 与 `docs/architecture/application/prompt-build/README.md`。展示是精简自定义骨架，不复刻完整默认顺序。主故事 Session 已含 Narrative，因此不另向 `@chat.narrative` 重复注入相同正文。历史消息保持 role 边界，最新输入独立。

五个小圆点支持定位，播放 / 暂停 / 重播延续统一样式；离屏或后台暂停，减少动态效果直接显示最终结构。素材失败不阻塞左侧演出。无业务请求或存储写入，图片是固定场景演示。

主标题无标点，无卡片外框、声明、底部进度线。类型检查用于验证组件集成，实际逐行节奏、阅读密度和窄屏排版待用户确认。

布局稳定：以不可见、aria-hidden / inert 的终态树在同宽度下保留真实高度，演出树在该区域内展开，避免播放控件随节点增长下移；没有写死高度或逐帧测量。桌面右侧图像底部对齐左侧完整内容，移动端仍自然接在左侧之后。
