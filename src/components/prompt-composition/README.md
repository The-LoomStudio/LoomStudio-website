# 角色组成与 Prompt Builder

已替换首页原记忆示意段落，入口 `/#prompt-builder`，位于叙事说明之后、工作台介绍之前。没有新增预览入口。

左侧依次展开三层：预设（身份、能力、可用工具）、Lore（角色、世界、场景）、用户输入。10 秒的一次播放中，右侧随左侧三层的出现同步展开示意推演文字；输入完成后，从右侧推演区域原位扩散为 ASCII，在同一网格上显出 Nom 窗边读书的完整插画 `nom-illustration-001.png`。使用首页优化图片输出，不使用贴纸。

角色决定语气，环境提供细节，当前行动推动回应。只表达本轮采用内容的组合关系；不把示意顺序当作固定产品顺序，不暗示所有挂载资料每轮必定进入上下文。

固定脚本，不调用模型，不展示真实模型推理，也不表示 Prompt Builder 生成图片。此段不再承担记忆、Session 延续或 Workspace 的产品说明。

保留进入视口播放一次、暂停、继续、重播与阶段切换；离开视口或切后台暂停；减少动态效果显示结果；移动端上下排列。视觉与节奏由用户在首页验收。

左侧内容逐层出现后保持可读，不再向右搬运字符或收成摘要。四个阶段按钮可暂停定位；减少动态效果时完整展示三层和插画。工具是可用能力示意，不表示本轮必然调用；未接真实 Agent 工具。
