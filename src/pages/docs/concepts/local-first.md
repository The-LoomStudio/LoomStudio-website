## 桌面工作区边界

Loom Studio 围绕本地工作区运行。结构化数据、二进制资产、媒体文件与系统凭证各自拥有明确的存储边界，绝无敏感密钥明文泄露

客户端通过受控 RPC 与本地服务通信，无需任何第三方云端中转，你的故事与角色设定完全属于你的设备

## 官方网站边界

当前发布的官方网站是完全独立的静态站点：

- 不部署任何公开的中间服务器
- 不索取或存储任何模型 API 密钥
- 不读取你的本地文件或私人创作
- 不收集用户隐私 Cookie 或任何追踪分析
- 所有的界面预览均使用精简的静态示意呈现

## 为什么坚持本地优先

真正的角色创作与长篇世界观构建，蕴含着创作者最珍贵的想象力与个人隐私。直接上云不仅伴随着高昂的服务器成本，更面临着数据泄露与平台审查的风险

将数据的主权交还给创作者，本地优先、离线可用，这是 Loom Studio 从第一天起就确立的底线原则
