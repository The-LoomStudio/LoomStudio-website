## 桌面工作区边界

Studio Server 在本机运行。SQLite 保存结构化权威状态，Blob Store 保存原始字节；API 凭据由系统凭据存储保管，应用记录保存受控引用。角色目录和导出文件是可编辑或分发入口，不是第二套运行数据库。

客户端通过受控 RPC 与本地服务通信。应用不提供自有云端中转；配置模型后，实际构建的上下文会发送给所选外部 Provider，因此“本地优先”不等于离线模型调用，也不意味着 Provider 不会收到请求内容。

## 官方网站边界

当前发布的官方网站是完全独立的静态站点：

- 不部署任何公开的中间服务器
- 不索取或存储任何模型 API 密钥
- 不读取你的本地文件或私人创作
- 不收集用户隐私 Cookie 或任何追踪分析
- 界面预览和演示图是静态示意，不连接真实工作区

## 为什么坚持本地优先

真正的角色创作与长篇世界观构建，蕴含着创作者最珍贵的想象力与个人隐私。直接上云不仅伴随着高昂的服务器成本，更面临着数据泄露与平台审查的风险

本地存储让创作者管理自己的项目数据；需要外部模型服务的功能仍依赖对应 Provider 的网络与服务。
